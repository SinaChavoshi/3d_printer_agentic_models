# 🧊 3D Printer Agentic Studio

[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.115+-009688.svg)](https://fastapi.tiangolo.com/)
[![Trimesh](https://img.shields.io/badge/Trimesh-4.0+-orange.svg)](https://trimesh.org/)
[![Three.js](https://img.shields.io/badge/Three.js-r128-black.svg)](https://threejs.org/)

An AI-powered parametric 3D CAD studio: describe a part in plain language and an LLM writes Python (`trimesh` + `manifold3d`) code that builds it. The code runs in a sandbox, the result is shown in an interactive WebGL viewer, and you can download a watertight binary `.stl` for 3D printing.

The repository also hosts a library of OpenSCAD models (with thumbnails and one-click OpenSCAD Playground links) and fishing-lure simulation tools.

## 🌟 Key Features

* **AI-Driven Parametric CAD:** An LLM (Gemini by default; Claude, GPT, Grok, DeepSeek, Kimi, or a self-hosted model) writes Python `trimesh` code for your part.
* **Sandboxed Execution:** Generated code runs in a separate, resource-limited process with a timeout, and can only use `trimesh`, `numpy`, and `math` (no file, network, or OS access).
* **Auto-Correction Loop:** If the code fails, the error, the failing code, and your request are sent back to the model to fix it (up to 2 retries). Failures are reported, never silently replaced.
* **Visual Refinement (Gemini):** The model inspects rendered snapshots of its own result and revises the code if it doesn't match the request.
* **Watertight CSG Booleans:** `manifold3d` engine for reliable unions, differences, and intersections.
* **Interactive 3D Viewer & Print Analyzer:** Three.js viewer with bounding box (mm), volume (mm³), face count, and watertight status; one-click binary `.stl` download.
* **OpenSCAD Model Library:** Hand-designed models with thumbnails and OpenSCAD Playground links (see the gallery above).

## 🏗️ Project Architecture

```
3d_printer_agentic_models/
├── app/
│   ├── cad_agent.py      # Multi-provider LLM agent: generation, auto-fix loop, visual refinement
│   ├── mesh_engine.py    # Sandboxed code execution, snapshots, STL/OBJ export
│   └── server.py         # FastAPI: /api/models, /api/generate, /api/generate_stream, /api/export/{id}/stl
├── static/
│   └── index.html        # Studio web UI (Three.js viewer)
├── generated_models/
│   └── openscad/<model>/ # <model>.scad, render.png, README.md (binary STLs are gitignored)
├── tools/
│   ├── decode_scad.py    # Extract .scad from an OpenSCAD Playground link
│   ├── encode_scad.py    # Build a Playground link from a .scad file
│   ├── render_scad/render.sh               # Render a model thumbnail (render.png)
│   ├── simulators/lure_hydrodynamics_simulator/  # Browser lure simulator
│   └── cfd/openfoam_lure/                  # OpenFOAM pipeline for high-fidelity lure CFD
├── tests/                # pytest suite (LLM calls are mocked)
├── Dockerfile
└── pyproject.toml
```

## 🚀 Getting Started

### Prerequisites
* Python 3.11 or higher
* [`uv`](https://docs.astral.sh/uv/) package manager (recommended) or `pip`
* Credentials for at least one LLM provider (see Configuration)

### 1. Installation

```bash
git clone https://github.com/SinaChavoshi/3d_printer_agentic_models.git
cd 3d_printer_agentic_models
uv sync
```

### 2. Running the Server Locally

```bash
uv run uvicorn app.server:app --host 127.0.0.1 --port 8088
```

Open **`http://localhost:8088`**. The server only listens on localhost by default; see the note below before exposing it.

### 3. Configuration

Copy `.env.example` to `.env` (or export the variables) and set what you need:

| Variable | Purpose |
| :--- | :--- |
| `GEMINI_API_KEY` *or* ADC + `GOOGLE_CLOUD_PROJECT` / `GOOGLE_CLOUD_LOCATION` | Google Gemini (API key or Vertex AI) |
| `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `XAI_API_KEY`, `DEEPSEEK_API_KEY`, `MOONSHOT_API_KEY` | Keys for other providers. Each key is only ever sent to its own provider. |
| `LLM_BASE_URL`, `LLM_API_KEY` | Endpoint (and optional key) for a self-hosted OpenAI-compatible server (default `http://localhost:11434/v1`). |
| `LLM_ALLOWED_BASE_URLS` | Comma-separated endpoints that users may pick in the UI's "Custom Base URL". Anything else is rejected. |
| `STUDIO_ACCESS_TOKEN` | If set, every API call must send it in the `X-Studio-Token` header (enter it in the UI settings). |
| `CORS_ALLOW_ORIGINS` | Extra origins allowed to call the API from a browser (off by default; the UI is same-origin). |
| `CAD_EXEC_TIMEOUT_SECONDS`, `CAD_EXEC_MEMORY_MB` | Sandbox limits for generated code (defaults: 60 s, 4096 MB). |

> [!WARNING]
> Users of the studio can make it call your LLM keys. If you bind to anything other than `127.0.0.1` or deploy the container, set `STUDIO_ACCESS_TOKEN`.

### 4. Docker

```bash
docker build -t cad-studio .
docker run --rm -p 127.0.0.1:8080:8080 --env-file .env cad-studio
```

## 🧩 Adding an OpenSCAD Model

```bash
# 1. Extract the active file from your OpenSCAD Playground share link
#    (prints a warning if the customizer overrides any defaults; add --apply-vars to keep them)
python tools/decode_scad.py "<playground-url>" generated_models/openscad/<name>/<name>.scad

# 2. Render the thumbnail (needs openscad + xvfb)
./tools/render_scad/render.sh generated_models/openscad/<name>/<name>.scad

# 3. After editing a .scad, regenerate its README link so it matches the code
python tools/encode_scad.py generated_models/openscad/<name>/<name>.scad --template-url "<old-url>"
```

Then add a `README.md` next to the model and a row to both gallery tables.
